# 组件规范

所有尺寸单位 px，颜色引用 `design-system.md`。组件类名前缀 `w-`（waste）。

## 1. 按钮 Button

| 类型 | 背景 | 文字 | 边框 | 用途 |
|---|---|---|---|---|
| primary | `#1F2937` | `#FFF` | 无 | 页面主操作（新建/保存/派单） |
| secondary | `#FFF` | `#1F2937` | `1px #C9D2DD` | 次级操作（导出/取消） |
| accent | `#2F6B8A` | `#FFF` | 无 | 筛选查询、抽屉提交 |
| danger | `#FFF` | `#B3261E` | `1px #B3261E` | 删除、驳回、取消任务（二次确认） |
| text | 透明 | `#3B627A` | 无 | 行内「查看」 |

- 高度 32 / 36 / 40，内边距 `0 16`，圆角 6，字重 500，字号 14
- 图标按钮：32×32，图标 16×16，`gap 6`
- 禁用：背景 `#EDF0F4`，文字 `#8A94A3`，`cursor: not-allowed`
- 按钮组间距 8；表格行内操作间距 12

## 2. 表单 Field

- 标签：宽 100–120px，右对齐，字号 14，色 `#5B6675`，必填前置 `<span style="color:#B3261E">*</span>`
- 输入框：高 36，内边距 `0 12`，边框 `1px #D6DDE6`，圆角 6，聚焦 `border-color:#2F6B8A; box-shadow:0 0 0 3px rgba(47,107,138,.12)`
- 单列宽 360–520；搜索区下拉宽 180–240
- 错误态：边框 `#B3261E`，下方 12px 红字「请输入点位编码」
- 只读字段（如系统生成的业务编号）背景 `#F5F7FA`，文字 `#5B6675`
- 日期/人员/组织/字典/级联一律使用对应选择组件，不用纯文本框

## 3. 表格 Table

- 表头：背景 `#F7F9FC`，字号 13，字重 500，色 `#5B6675`，高 44，下边框 `1px #E3E8EF`
- 行高 48，下边框 `1px #EEF1F5`，悬停 `#FAFBFD`
- **表头不写死固定宽度**，按内容设 `min-width` 并允许横向滚动；编号、状态、日期、操作列 `white-space: nowrap`
- 数字列右对齐 + `tabular-nums`
- 空状态：居中图标 + 「当前筛选条件下无记录」+ 主按钮「新建清运任务」
- 底部分页：左「共 128 条」，右页码 + 每页条数（10/20/50）

## 4. 状态标签 Tag

| 语义 | 文字色 | 背景 | 左边框 |
|---|---|---|---|
| 待处理/待生成 | `#B26B00` | `#FDF6E7` | `2px #B26B00` |
| 处理中/清运中 | `#2F6B8A` | `#EAF2F6` | `2px #2F6B8A` |
| 已完成/已通过 | `#2E7D5B` | `#EAF4EF` | `2px #2E7D5B` |
| 异常/驳回 | `#B3261E` | `#FBEDEC` | `2px #B3261E` |
| 停用/中性 | `#5B6675` | `#F1F3F6` | `2px #8A94A3` |

高 22，内边距 `0 8`，圆角 4，字号 12，**必须带中文文字**。

## 5. 卡片 Card

- 背景 `#FFF`，边框 `1px #E3E8EF`，圆角 8，**无阴影**
- 头部高 52，内边距 `0 20`，标题 16/600，右侧放操作
- 内容内边距 20；卡片间距 16
- 指标卡：标题 13 `#5B6675`，数值 26/600 `#1F2937`，环比 12（涨 `#B3261E` / 跌 `#2E7D5B`，因是国内业务惯例）

## 6. 抽屉 Drawer

- 宽 560（表单）/ 720（详情），右侧滑入，`box-shadow: 0 8px 32px rgba(27,36,48,.16)`
- 头部高 56，标题 + 关闭；底部固定操作区高 64，右对齐按钮组
- 打开时遮罩 `rgba(27,36,48,.45)`；关闭前若有未保存内容弹确认

## 7. 弹窗 Dialog

- 宽 420（确认）/ 640（表单），圆角 8，阴影 `0 12px 40px rgba(27,36,48,.20)`
- 标题 16/600，内容 14/22，底部按钮右对齐，间距 8
- 危险确认：图标 `#B3261E` + 明确后果文案 + 红色描边确认按钮

## 8. 分页 Pagination

- 高 32，页码按钮 32×32，圆角 6，当前页背景 `#1F2937` 白字
- 左右箭头 32×32，禁用态 `#8A94A3`
- 右侧「每页 10 条」下拉宽 100

## 9. 其他

- 时间轴：左侧 2px `#E3E8EF` 竖线，节点 8px 圆点（进行中 `#2F6B8A`，完成 `#2E7D5B`，异常 `#B3261E`），右侧事件名 + 操作人 + 时间 + 原因
- 上传：虚线框 `1px dashed #C9D2DD`，拖拽区高 120，支持进度条、类型/大小提示、删除确认
- 消息铃铛：右上角红点数字，点开右侧抽屉列表，含业务编号与详情跳转
- 骨架屏：`#EEF1F5` 占位条，1.2s 呼吸动画
